# MyPortfolio — Frontend

A personal portfolio website built with React and Bootstrap 5.

🌐 **Live Site** → [iam-kumaresan.netlify.app](https://iam-kumaresan.netlify.app/)

---

## Built With

- React 18 + Vite
- Bootstrap 5
- react-icons
- react-simple-typewriter
- axios
- react-toastify

---

## Sections

- **Home** — Intro with typewriter effect and CTA buttons
- **About** — Bio, experience highlights, resume download
- **Skills** — ReactJS, Node.js, MongoDB, Express, Git, HTML, CSS
- **Experience** — Mindtree apprenticeship + GUVI certification
- **Projects** — Password Reset App, Music Streaming App, Blog Application
- **Contact** — Contact form connected to backend API

---

## Getting Started

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```

## Backend

The contact form connects to a separate Express + Nodemailer backend.

- Repo → [kumaresh231299/portfolio_be](https://github.com/kumaresh231299/portfolio_be)
- Update the API URL in `Contact.jsx` before deploying
